# 🎵 Melodify Downloader

ابزاری ساده و سبک برای دانلود آهنگ‌ها از پلی‌لیست و پروفایل هنرمندان در [Melodify](https://pwa.melodify.app) از طریق خط فرمان.

---

## ✨ امکانات

- دانلود آهنگ‌ها از **پلی‌لیست** و **پروفایل هنرمند**
- انتخاب کیفیت دانلود (بالا / متوسط / پایین)
- سیستم محدودیت روزانه دانلود برای جلوگیری از بن شدن اکانت
- نمایش پیشرفت دانلود هر آهنگ به صورت لحظه‌ای
- ذخیره خودکار فایل‌ها در پوشه‌های مرتب بر اساس نام هنرمند یا پلی‌لیست
- پشتیبانی از ویندوز و لینوکس

---

## 📁 ساختار پروژه

```
melodyfi_downloader/
├── melodify_downloader.py   # فایل اصلی اسکریپت
├── information.py           # هدرها و اطلاعات اکانت (باید ویرایش شود)
├── requirments.txt          # پکیج‌های مورد نیاز
├── history.csv              # فایل سابقه دانلود (خودکار ساخته می‌شود)

    ├── playlists/           # آهنگ‌های دانلود شده از پلی‌لیست
    └── artists/             # آهنگ‌های دانلود شده از پروفایل هنرمند
```

## 🔧 راه‌اندازی اولیه

### ۱. استخراج هدرها از مرورگر

قبل از استفاده از اسکریپت، باید هدرهای HTTP مخصوص اکانت خود را استخراج و در فایل `information.py` قرار دهید:

1. وارد اکانت Melodify خود در مرورگر شوید
2. ابزار توسعه‌دهنده مرورگر (F12) را باز کنید
3. به تب **Network** بروید
4. یک آهنگ را پخش کنید یا وارد یک پلی‌لیست شوید
5. درخواست‌های مربوط به `https://melodify.pw/api/` را پیدا کنید
6. مقادیر زیر را از هدرهای درخواست کپی کنید و در فایل `information.py` جایگذاری کنید:

| متغیر | توضیح |
|--------|-------|
| `Authorization` | توکن احراز هویت |
| `Device_Id` | شناسه دستگاه |
| `Device_Name` | نام دستگاه |
| `Device-Token` | توکن دستگاه |
| `User_Id` | شناسه کاربر |

### ۲. ویرایش فایل information.py

مقادیر استخراج شده را در فایل `information.py` جایگزین کنید:

```python
Authorization = "Bearer YOUR_TOKEN_HERE"
Device_Id = "your_device_id"
Device_Name = "your_device_name"
Device-Token = "your_device_token"
User_Id = "your_user_id"
```

> ⚠️ **هشدار:** فایل `information.py` حاوی اطلاعات حساس اکانت شماست. این فایل را در مخزن Git قرار ندهید و با کسی به اشتراک نگذارید.

## 🚀 نحوه استفاده

### دانلود از پلی‌لیست

```bash
python melodify_downloader.py -u https://pwa.melodify.app/playlist-songs/PLAYLIST_ID
```

### دانلود از پروفایل هنرمند

```bash
python melodify_downloader.py -u https://pwa.melodify.app/artist-profile/ARTIST_ID
```

### تنظیم کیفیت دانلود

```bash
# کیفیت بالا (پیش‌فرض)
python melodify_downloader.py -u URL -q high

# کیفیت متوسط
python melodify_downloader.py -u URL -q medium

# کیفیت پایین
python melodify_downloader.py -u URL -q low
```

### تغییر محدودیت دانلود روزانه

مقدار پیش‌فرض محدودیت **۵۱۲۰ مگابایت (۵ گیگابایت)** است. برای تغییر آن:

```bash
# محدودیت ۸ گیگابایت
python melodify_downloader.py -u URL -l 8192

# محدودیت ۲ گیگابایت
python melodify_downloader.py -u URL -l 2048
```

### نمونه کامل

```bash
python melodify_downloader.py -u https://pwa.melodify.app/playlist-songs/abc123 -q medium -l 8192
```

## 📌 پارامترها

| پارامتر | توضیح | پیش‌فرض | اجباری |
|----------|-------|---------|--------|
| `-u` | لینک پلی‌لیست یا پروفایل هنرمند | - | ✅ |
| `-q` | کیفیت دانلود (`high` / `medium` / `low`) | `high` | ❌ |
| `-l` | محدودیت دانلود روزانه (مگابایت) | `5120` | ❌ |

---

## 📝 نکات مهم

- **محدودیت روزانه:** ملودیفای به طور کلی اجازه دانلود روزانه **۱۰ گیگابایت** را می‌دهد. اسکریپت به صورت پیش‌فرض محدودیت **۵ گیگابایت** دارد. اگر از محدودیت عبور کنید، اسکریپت یک هشدار نمایش می‌دهد و از شما تأیید می‌گیرد.
- **فایل سابقه:** اطلاعات دانلود روزانه در فایل `history.csv` ذخیره می‌شود.
- **جلوگیری از دانلود تکراری:** اسکریپت به صورت خودکار آهنگ‌های قبلاً دانلود شده را تشخیص داده و از دانلود مجدد آن‌ها صرف‌نظر می‌کند.
- **فعال‌سازی دستگاه:** اگر با خطای `you need to active the account for your device` مواجه شدید، باید دستگاه خود را در اکانت Melodify فعال کنید.

## 🛠️ عیب‌یابی

| مشکل | راه‌حل |
|------|--------|
| `the url is not valid` | مطمئن شوید لینک از نوع `https://pwa.melodify.app/playlist-songs/` یا `https://pwa.melodify.app/artist-profile/` باشد |
| `you need to active the account for your device` | دستگاه خود را در اکانت Melodify فعال کنید |
| `you reached into download limit` | محدودیت دانلود روزانه تمام شده است. می‌توانید با تأیید ادامه دهید (خطر بن شدن اکانت وجود دارد) |
| خطا در پکیج‌ها | مطمئن شوید پکیج‌ها را با `pip install -r requirments.txt` نصب کرده‌اید |
